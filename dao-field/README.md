## 核心方程

```
ẋᵢ = α·xᵢ₋₁(1−xᵢ) − α·xᵢ(1−xᵢ₊₁)   // 相生（cycle）
   + β·xᵢ₊₂(1−xᵢ) − β·xᵢ(1−xᵢ₋₂)   // 相克（diagonal）
   + ε·sin(ωt + 2πi/5)              // 驱动（零和）
```

五节点，指标 mod 5，α, β, ε > 0。每一项都是多项式——**零分支**。
`(1 − xᵢ)` 是刹车：xᵢ → 1 时流入归零。

## 为什么没有 `if`

饱和就是 `(1 − xᵢ)`——普通乘法。
xᵢ → 1 时流入归零；xᵢ → 0 时流入最大。**系统自己刹车，没有一条分支指令。**

> **Balance as a property of the flow, not a set of rules.**

## 双层壳（核心机制）

```
第一层壳：相生相克（守恒）
  → 极端被推回中心

第二层壳：物极必反 · 否极泰来（饱和 + 负实部）
  → 中心本身是消解装置（死点）
```

**第一层不让你越界，第二层不让你停在界内唯一不动点。**

结果：**走出去被推回来，站住了被磨掉。**
状态空间里没有一个可以久留的点——唯一留出的活路是**两条缝**：

- **缝 1**：δ 驱动项（外部注入）→ 封闭系统必死
- **缝 2**：慢变量（总量 K 或耦合强度带动力学）→ 如太阳死亡，燃料消耗，K(t) 衰减

> 活下去的唯一秘密：**没有关死门，并且永远不让自己回到绝对的 50-50。**
