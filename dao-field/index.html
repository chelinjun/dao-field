One equation

ẋᵢ = α·xᵢ₋₁(1−xᵢ) − α·xᵢ(1−xᵢ₊₁)   // generation (cycle)
   + β·xᵢ₊₂(1−xᵢ) − β·xᵢ(1−xᵢ₋₂)   // inhibition (diagonal)
   + ε·sin(ωt + 2πi/5)              // drive (zero-sum)

Five nodes, indexed modulo 5. α, β, ε > 0. Every term is a polynomial — zero case distinctions. The (1 − xᵢ) factor is the brake: as a node approaches 1, inflow automatically goes to zero.

Four results

Note on the spectrum. At x* = 1/5 the Jacobian is circulant with first row [−(α+β), 0.2α, 0.8β, 0.2β, 0.8α]. Its exact eigenvalues are λ_k = −(α+β) + 0.2α·ωᵏ + 0.8α·ω⁻ᵏ + 0.8β·ω²ᵏ + 0.2β·ω⁻²ᵏ, where ω = e^(2πi/5). A simplified form λ_k = −(α+β) + α·ωᵏ + β·ω²ᵏ gives the correct real parts (the stability-relevant part) but wrong imaginary parts, because it assumes inflow/outflow are symmetric. Only the real parts matter for Prop. 2. The imaginary parts set the spiral period.

Why no if

Saturation is (1 − xᵢ) — plain multiplication. As xᵢ → 1 inflow goes to zero; as xᵢ → 0 inflow is maximal. The system brakes itself with no branch instruction. Balance as a property of the flow, not a set of rules.

The counterexample

xₜ₊₁ = 1 − xₜ. Apply twice: xₜ₊₂ = xₜ. Every orbit is exact period-2, multiplier μ = (−1)(−1) = +1, neutrally stable. A language model stuck repeating one phrase is this system: a state, a flip, no saturation, no third dimension.

The difference between a living cycle and a dead loop is the distance of |μ| from 1.

What this is not

  • Not a theory of everything.
  • Not a prediction engine.
  • Not a claim about any tradition. (Call them A–E — same result.)

The ledger is conserved; the spectrum contracts; the drive wakes without spending. Everything else — how you read your own entry — is the only variable left open.
