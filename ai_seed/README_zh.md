# 天道种子 (TianDao Seed)
**本地优先的五节点守恒内核 —— 共享法则 × 私有状态**

*一个最小却完整的分布式分配引擎原型：五个节点在硬零和约束下争夺流量。需求驱动重分配把流量导向需要的地方，而每次使用都在私人的个性化层留下永久印记。一切本地运行，一切留在你的机器上。*

## 一、这是什么？

天道种子是一句概念的最小可运行实现：

> **死的法则 × 活的状态 = 本地生成的差异**

- **法则层（`allocate`）是死的**：一套固定、可审计、免训练的守恒流动力学。它不学习，只执行。
- **状态层（`x`、`γ`）是活的**：它随每次交互改变，且只随**你**的交互改变。没有任何别人的种子会和你的一样。
- **身份不是被设计的**。它是你从均匀态 `[1,1,1,1,1]` 出发的私人使用史的残差。你的 `γ` 向量就是你的指纹。

> 注：代码里的节点名已英文化（Compute / Data / Task / Memory / Collab），与英文 README 一致；中文文档里仍用「算力 / 数据 / 任务 / 记忆 / 协作」方便阅读。

### 2.1 法则层 —— `allocate()`

五节点硬守恒环：

```text
算力 · 数据 · 任务 · 记忆 · 协作
```

每一步：

```text
gen  = a · ( x[前]·(1−x[i]) − x[i]·(1−x[后]) )     # 相邻：激发
inh  = b · ( x[后2]·(1−x[i]) − x[i]·(1−x[前2]) )   # 非相邻：抑制
drive = need[i]·γ[i] − mean(need·γ)                # 零和 需求注入
x[i] += dt · ( gen + inh + drive )
Σx = 1                                              # 硬归一：零和
```

- **守恒**：`Σx ≡ 1.0` 在**每一步**都成立（驱动项零和，账本在解析上就被保住——已验证：200 步最大偏离 `0.00e+00`）。一个节点的得就是另一个的失。这不是特性，这是法则。
- **需求注入**：`NEED` 向量（由关键词意图生成）把流量推向当前任务所需处。因为驱动零和，强化一个被用到的通道会自动稀释闲置通道——选择是守恒的副作用，不是另一条规则。
- **归一是隐藏机制**：因为 `Σ = 1`，增大一个被用通道必然缩小其他通道。选择是守恒的副产物。

### 2.2 生长层 —— `γ`

每次使用强化被选中通道的增益：

```python
d["g"][idx] = min(d["g"][idx] * 1.08 * 0.995, 8.0)
```

- `× 1.08` —— 赫布项：一起激发，一起连线。
- `× 0.995` —— 遗忘项：用进废退。对慢变量的轻微刹车。
- `min(·, 8.0)` —— **硬上限。这才是真正的护盾。** 没有它，同一意图重复约 200 次会把 `γ` 推到 `≈ 4.8 × 10⁶`；账本（`Σx=1`）仍成立，但参数数值爆掉。上限让 `γ` 可读、有界。

> **两条叠加的反馈环，诚实地说**：`0.995` 单独并**不**创造稳定均衡——`1.08 × 0.995 = 1.0716 > 1`，所以 `γ` 仍单调递增到上限（约 30 次触顶，无刹车时约 27 次）。是上限在驯服它。真正的衰减均衡需要 `decay = 1/1.08 ≈ 0.926`，而非 `0.995`。我们保留 `0.995` 作温和刹车；天花板才是解法。

## 三、怎么跑

```bash
# 依赖：Python 3.7+，零 pip 依赖
# Windows
start.bat
# Linux / macOS
./start.sh        # 或：python3 app.py
# → 浏览器自动打开 http://127.0.0.1:8000
```

> **双击说明：** 双击 `start.bat` 会弹出一个**黑色 CMD 窗口**，那就是服务器本身，**别关**。端口绑好后浏览器自动打开（不再抢跑）。若窗口瞬间关闭或报红字，把红字截图发我。若 8000 被上次没关干净的进程占用，服务器自动换到 8001/8002…，注意浏览器实际打开的地址。

打字即可。内核会：
1. 把文字分类成意图（`code` / `mem` / `write` / `collab`）——纯关键词匹配（中英），无神经网络，离线。
2. 在五个节点间重分配流量（`x`，显示 `Σ=1.00`）。
3. 唤醒流量份额最大的通道。
4. 让该通道的 `γ` 生长——从此你的种子永久不同。

所有状态落在 `seed_state.json`。无账号、无云、无遥测。HTTP 只绑 `127.0.0.1`——完全离线可玩。

## 四、设计纪律

刻意排除，及理由：

| 排除项 | 理由 |
|---|---|
| 云同步 | 种子的全部价值在于状态只留在**你**机器上 |
| 登录 / 账号 | 你的机器即身份；`γ` 即密码 |
| LLM 意图解析 | 种子应当粗糙。关键词匹配免费、可审计、离线 |
| Electron / Vue / 框架 | 壳只是嘴和眼，不是脑。约 40 行原生 JS 够当嘴 |

**铁律：先把法则做到无懈可击，再给它穿衣服——顺序不可反。**

## 五、设计验证实验（含数值预测）

把同一意图喂 200 次，看 `γ(t)`——项目的体检：

- **无上限（纯 `× 1.08`）** → `γ` 溢出：10 次 `≈2.2`、30 次 `≈10`、50 次 `≈47`、200 次 `≈4.8×10⁶`。账本仍成立（`Σx=1`），但参数爆掉，重复通道完全 lock-in（`x → ~0.99`）。数值丑，但不崩。
- **有上限 `8.0`（+ `0.995` 刹车）** → `γ` 约 **30 次**爬到上限并停在 `8.0`；重复通道 lock-in 在 `x ≈ 0.86` 并维持。有界、可复现、活着。

两条曲线：一条溢出成无意义数字，一条饱和成稳定可读状态。差别在**上限**，不在衰减项。lock-in（单通道主导）两者都有——而这正是要点：*你的种子长成了你*。上限只是让数字保持清醒。

## 六、原则（一页）

1. **差异是唯一货币。** 完美均匀与完美周期都是零差异态。系统只靠维持梯度来运算。
2. **钟摆：分散 → 集中 → 标准化 → 商品化 → 分散。**
3. **棘轮。** 每一轮标准化都沉积一层，永不回滚。
4. **法则沉淀，差异重生。** 守恒是死的、可共享、可审计。状态是活的、局部的、不可转让。下一波价值不在"压缩大模型"，而在 **死的法则 × 私有数据**。
5. **没有绝对的对，但有确定的错。** 法则层之所以有力，正因它能拒绝。敢说"不"的系统才可被信任。
