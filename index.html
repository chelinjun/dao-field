Bug #1 — Demo 10: Fourier Coefficient Sign Alternation

What went wrong: Analytical solution missed sin(nπ/2) sign alternation (n=3,7,11... had wrong sign). Peak was 0.742 instead of 1.0.

Why: Probabilistic model (AI) hallucinated the coefficient formula.

Bug #2 — Demo 14: BSGS Used Forward Multiplication

What went wrong: Baby-Step Giant-Step used forward multiplication instead of modular inverse.

Why: Classic algorithmic error.

How caught: gˣ mod p verification failed on 3 test cases.

Fix: Replaced with inverse-element method. All 3 passed.

Takeaway: Verification doesn't care about implementation — only about the math.

Bug #3 — Demo 19: Phase-Domain Laplacian Divergence

What went wrong: Laplacian smoothing on phase (mod-2π) caused wrap-around artifacts.

Why: Phase is topologically S¹; Laplacian on periodic domain is mathematically illegal without lifting.

How caught: ε-sweep showed strictly monotonic PSNR degradation.

Fix: ε→0. Standard GS is already optimal.

Takeaway: The best field operator is no operator at all. 道法自然。

Bug #4 — Demo 20: Divergence at Source/Sink Points

What went wrong: Verifying ∇·v=0 globally, including source/sink where divergence is physically non-zero.

Why: Naive verification criterion without physical boundary understanding.

How caught: Point inspection showed non-zero exactly at source/sink coordinates.

Fix: Restricted ∇²P≈0 to non-source/sink points only.

Takeaway: The verification method matters as much as the result.

Bug #5 — Demo 23: Jacobi Iteration Unstable for Helmholtz

What went wrong: Jacobi solver on Helmholtz equation diverged.

Why: When k²dx² > 0, spectral radius > 1 — mathematical non-convergence by design.

How caught: Residual grew each iteration.

Fix: Switched to analytical eigenmode + high-res finite difference.

Takeaway: Physics dictates the method, not the other way around.
